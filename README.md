# MinigamesMod + Block Blast

Сборка мода [MinigamesMod](https://modrinth.com/mod/minigamesmod) (автор TRIVAIT/Ulitkad) с добавленной мини-игрой **Block Blast**.

Оригинальный репозиторий: https://github.com/TRIVAIT-MODS/MinigamesMod
Лицензия: MIT (унаследована от оригинала, см. LICENSE).

## Что такое Block Blast

Классическая головоломка: поле 8×8, лоток из трёх фигур, заполненные ряды и столбцы очищаются одновременно.

- **Управление** — полноценный drag-and-drop: зажал фигуру → она в руке (следует за курсором, масштабируется над полем), призрачный предпросмотр показывает, куда встанет (зелёный — можно, красный — нельзя), отпустил — ставится, мимо поля — возвращается в лоток.
- **Комбо** — каждая установка с очисткой повышает множитель, установка без очистки сбрасывает. Очки очистки: `(линии×10 + 5×(доп. линии)) × комбо`. Плашка «КОМБО xN» всплывает под полем и затухает.
- **Рекорды** — лучший счёт и лучшее комбо хранятся в конфиге (`config/minigames/blockblast.json`), счёт фиксируется и при выходе с экрана.
- Анимация вспышки на очищенных клетках, звуки с растущим тоном, локализация EN/RU.

Собранные JAR лежат в Releases.

## Сборка

```bash
JAVA_HOME=/path/to/jdk25 ./gradlew build   # ветка main (MC 26.3)
JAVA_HOME=/path/to/jdk21 ./gradlew build   # ветка 1.21
```

Готовый JAR: `build/libs/minigamesmod-<version>.jar` — положить в `mods/` вместе с Fabric API и Cloth Config (ModMenu опционален).

## Отличия от апстрима и известное

- В апстриме `leaderboard/LeaderboardLink.java` и `minigame/minesweeper/leaderboard/LeaderboardLink.java` добавлены в `.gitignore`, поэтому из GitHub апстрим **не собирается**. Здесь оба файла восстановлены и строки убраны из `.gitignore`. URL-ы внутри — публичные константы, они и так распространяются внутри каждого выпущенного JAR.
- Тексты лидербордов отправляются в Google Sheets только если это включено в настройках мода.
